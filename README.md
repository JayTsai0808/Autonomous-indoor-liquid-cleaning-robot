# Autonomous Indoor Liquid Cleaning Robot

## Project Overview

This project aims to develop a compact autonomous mobile robot capable of detecting and cleaning indoor liquid spills using computer vision.

The robot follows a predefined patrol route, continuously scans the floor for rabbit urine, navigates toward the detected liquid, removes it using an onboard suction system, resumes the interrupted patrol, and automatically returns to a wireless charging dock after completing its mission.

This project serves as a robotics engineering portfolio that integrates mechanical design, embedded systems, computer vision, artificial intelligence, autonomous navigation, and system integration.

---

## Motivation

Pet owners often need to manually inspect indoor environments and clean liquid waste throughout the day.

The objective of this project is to automate this repetitive task by developing an autonomous indoor service robot capable of detecting and removing rabbit urine without human intervention.

---

## Objectives

- Design a compact autonomous mobile robot
- Detect rabbit urine using computer vision
- Navigate toward the detected target
- Remove liquid using a suction system
- Resume the interrupted patrol route
- Return to a wireless charging dock automatically
